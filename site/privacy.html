Privacy Policy for Diktiv

Version of 29 September 2026

Translation. Only the German version is binding.

Summary

Diktiv converts your speech into text on your device. Recordings and dictations do not leave your device. There is no tracking, no usage statistics and no crash reports sent to me. Data only goes to others if you switch on or set up a feature for it yourself. Section 3 lists these features.

1. Controller

Michael Aebi, private individual c/o Aebi, Fabrikstrasse 4, 8867 Niederurnen, Switzerland Email for privacy matters: privacy@diktiv.com

2. What stays on your device

Speech recognition runs entirely on your device. The speech recognition model is included in Diktiv. There is no cloud version of the recognition.

Diktiv stores the following data in your Windows user profile and does not transmit it:

Data Location Note
Settings %APPDATA%\Diktiv An access key entered for AI post-processing is stored encrypted by Windows.
Usage counter %APPDATA%\Diktiv Counts recordings for the limits of the free version.
Debug log %APPDATA%\Diktiv Technical information for troubleshooting, without the dictated text.
Device ID %APPDATA%\Diktiv Only for the licence check, see section 3.4.
History %LOCALAPPDATA%\Diktiv Your texts and the names of the windows you dictated into. At the first start you choose whether it is kept only until Diktiv closes, for 30 days or for 90 days.
Original recordings %LOCALAPPDATA%\Diktiv Only if you switch on keeping them in the settings. Off by default.

If your Windows profile is stored on a server (roaming profile, for example in a company), Windows may copy the folder %APPDATA%\Diktiv to other devices. History and recordings are therefore deliberately kept in %LOCALAPPDATA%, which does not roam.

To insert text, Diktiv briefly places it on the Windows clipboard. By default, Diktiv marks it so that it does not appear in the Windows clipboard history or the Windows cloud clipboard, and removes it again afterwards. If you switch off pasting via the clipboard, Diktiv types the text and does not use the clipboard.

3. When data leaves your device

3.1 Microsoft Store

If you get Diktiv from the Microsoft Store, the download and updates are handled by Microsoft. What Microsoft processes is governed by Microsoft's privacy statement.

3.2 Another speech recognition model

If you choose a model other than the included one in the settings, Diktiv downloads it from Hugging Face (USA). Only the model file is retrieved. No recordings or texts are transmitted. As with any connection, Hugging Face sees your IP address.

3.3 AI post-processing, only if you set it up

Diktiv can have a language model revise the recognised text. To do this, you enter the address and access key of a provider of your choice yourself. Without this entry, nothing is transmitted. With it, Diktiv sends the recognised text, never the recording, to exactly this provider whenever you use a feature that needs it. This also applies to recognising appointments in a dictation.

You enter into a separate contract with the provider. What it does with the text is governed by its privacy policy. If you run the language model yourself on your device or in your own network, the text does not leave your device or network.

Dictations often contain confidential information. Check whether you may pass them to an external provider before you switch on this feature.

3.4 Licence check, only with a licence key

The free version does not need a licence key and does not contact the licence service. If you enter a licence key, Diktiv sends the key and a device ID to license.diktiv.com when activating, when deactivating and at every start. This checks that a key runs on no more than three devices at the same time.

The device ID is a shortened SHA-256 hash of processor and mainboard identifiers. The original identifiers cannot be derived from it. If none are available, Diktiv creates a random ID without any link to the hardware.

The key, device IDs and licence status are stored for as long as the licence exists. Diktiv itself does not log your IP address. The server operator may see it briefly in connection logs for technical reasons.

3.5 Google Calendar, only if you connect it

You can connect Diktiv to your Google Calendar so that a dictation becomes an appointment. To do this, you set up access with Google yourself and sign in to Google. Only then does Diktiv send the title, description, start and end of the appointment to Google (USA). The access to your Google account is stored in %APPDATA%\Diktiv. What Google does with the data is governed by Google's privacy policy.

4. What Diktiv does not do

No telemetry, no usage statistics, no automatic crash reports, no tracking, no advertising, no sale of data. Diktiv contains no components for any of this.

Recipients in the USA are not subject to the same level of protection as in Switzerland. These transfers only take place because you use the respective feature yourself.

6. Your rights

Under the Swiss Data Protection Act, you can request information about your data, its correction or its deletion. Almost all data is on your device. You can view and delete it yourself in the folders from section 2. You can also delete the history directly in Diktiv. For data held by the licence service, write to privacy@diktiv.com.

If you live in the EU or EEA, you also have the rights under the General Data Protection Regulation (GDPR). These include access, rectification, erasure, restriction of processing, data portability and objection. You can also lodge a complaint with the data protection authority of your country of residence. In Switzerland, this is the Federal Data Protection and Information Commissioner (FDPIC).

7. Changes

If the way Diktiv handles data changes, I will update this policy. The current version is available on diktiv.com. This policy exists in German and English. Only the German version is binding.
