Quick questions

Do I need an internet connection?

Not for dictation with the included German model. You need internet to install Diktiv from the Microsoft Store and to download additional models.

Where can I insert my text?

In the input field you are working in, for example in Word, Outlook, a browser or a terminal. For applications with special requirements you can set the paste method.

Is the recognised text always correct?

Speech recognition makes mistakes. Review the text before using it. Diktiv is not a medical device.
